===================================================

Как загрузить на GitHub (с компьютера)
--------------------------------------
1. Распакуйте архив на компьютере.
2. Откройте https://github.com/dap2711/index
3. Нажмите «Add file» -> «Upload files».
4. Перетащите в окно ВСЕ файлы и папки из распакованной папки. Папки перетаскиваются целиком.
5. Внизу нажмите зелёную кнопку «Commit changes».
6. Откройте Settings -> Pages. Source = «Deploy from a branch», Branch = «main», папка «/ (root)». Save.
7. Через 1-3 минуты сайт откроется: https://dap2711.github.io/index/

Как вносить изменения потом
---------------------------
Способ 1 (проще всего): Add file -> Upload files, перетащить новые версии файлов. Файлы с тем же именем
заменяются. Нажать Commit changes. Через 1-3 минуты изменения на сайте.
Способ 2 (мелкие правки): открыть файл в репозитории, нажать значок карандаша, изменить, Commit changes.
После обновления откройте сайт и обновите страницу (на телефоне при необходимости закройте и откройте вкладку).

Не пропадут ли напоминания при обновлении
-----------------------------------------
Нет. Напоминания хранятся не в файлах сайта, а в хранилище браузера (по адресу dap2711.github.io).
Замена index.html их не трогает. Информация пропадёт, только если: очистить данные сайта в браузере,
открыть сайт по другому адресу (другой домен), удалить браузер или работать в приватной вкладке.
Страховка: подключите синхронизацию Google Drive (значок облака рядом со строкой дат).

Как добавить новую страницу
---------------------------
Создайте папку (например, zametki), положите в неё index.html, загрузите папку в репозиторий.
Страница откроется по адресу https://dap2711.github.io/index/zametki/

Статистика нажатий
------------------
Приложение считает, какие кнопки нажимаются и сколько раз (только названия кнопок, без текста напоминаний).
Если подключён скрипт Google Apps Script (окно ⏰ -> «Подключение отправки»), счётчики раз в минуту
после нажатий отправляются в скрипт, а 1-го числа каждого месяца в 8 утра он присылает письмо со статистикой
за прошлый месяц. После замены кода скрипта: Развёртывание -> Управление развёртываниями -> Изменить ->
Новая версия, и один раз запустите функцию setup.

Важно про хранилище
-------------------
Все сайты вашего аккаунта на github.io (index, my-menu и другие) используют одно общее хранилище браузера.
У Напоминалки ключи начинаются с «nap_», чтобы не пересекаться с другими страницами.
